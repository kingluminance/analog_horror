# 쓰레기통 천사 캐릭터 - 날개 애니메이션 에셋

## 폴더 구성

```
sprites/
  body_open_lid_eyes.png         # 뚜껑 열림 + 눈 3개 (몸통만, 날개 제거됨)
  body_closed_lid_eyes.png       # 뚜껑 닫힘 + 눈 3개 (몸통만)
  body_closed_lid_noeyes.png     # 뚜껑 닫힘 + 눈 없음 (몸통만)
  wing_flap/
	wing_flap_00.png ~ 07.png    # 날개 퍼덕임 8프레임 (왼쪽 날개 기준)
wing_flap_frames.tres            # Godot 4용 SpriteFrames 리소스 (애니메이션 "flap")
TrashAngel.tscn                  # 몸통 + 양쪽 날개 조립 예시 씬
```

## 어떻게 만들었나

원본 이미지 3장에서 초록 배경을 제거하고(크로마키), 몸통이 날개를 가리는 영역만 남기는 방식으로 **날개 없는 몸통**만 깔끔하게 잘라냈습니다.

날개는 img1(뚜껑 열림 포즈)에서 왼쪽 날개만 통째로 오려낸 뒤, 어깨 부착점을 축으로 8단계 회전시켜서 퍼덕이는 애니메이션을 만들었습니다. AI로 매 프레임을 새로 생성하면 깃털 모양이 프레임마다 미묘하게 달라져서 떨림이 생기기 때문에, 이 방식(하나의 원본을 회전)이 훨씬 안정적입니다.

## Godot에 적용하는 법

1. `sprites/` 폴더와 `wing_flap_frames.tres`, `TrashAngel.tscn`을 프로젝트에 그대로 복사 (경로가 `res://sprites/...`로 참조되어 있으니 프로젝트 루트에 넣는 게 가장 간단합니다)
2. `TrashAngel.tscn`을 열면 바로 몸통 + 양쪽 날개가 퍼덕이는 상태로 재생됩니다
3. 원하는 씬에 이 `.tscn`을 인스턴스로 가져다 쓰거나, 구조를 참고해서 직접 조립하세요

### 구조 원리
- `WingLeft`, `WingRight` (AnimatedSprite2D)를 먼저 넣고 그 다음에 `Body` (Sprite2D)를 넣어서, 날개 뿌리가 몸통 뒤로 자연스럽게 가려지게 했습니다
- `WingRight`는 `WingLeft`와 같은 프레임을 쓰되 `flip_h = true`로 좌우 반전 — 각인된 회전 각도도 함께 반전되기 때문에 양쪽이 자연스럽게 대칭으로 움직입니다
- `offset` 값은 각 프레임 안에서 날개 뿌리(어깨 부착점)가 어디 있는지를 보정해서, `position`에 지정한 좌표에 딱 맞물리게 하는 값입니다

### 몸통을 바꾸고 싶다면
`Body`의 `texture`를 `body_closed_lid_eyes.png`나 `body_closed_lid_noeyes.png`로 교체하면 됩니다. 세 몸통 모두 크기가 비슷해서 날개 위치(`WingLeft`/`WingRight`의 `position`)는 크게 안 바꿔도 되지만, 눈 위치가 조금씩 다르니 미세 조정이 필요할 수 있습니다.

## 애니메이션 속도/강도 조절

- **속도**: `wing_flap_frames.tres`의 `speed` 값(현재 8.0 = 초당 8프레임)을 올리면 빠르게, 내리면 천천히 퍼덕입니다
- **강도**: 지금은 완만하게 위아래로 젓는 정도입니다. 더 크게 펄럭이길 원하시면 말씀해주세요 — 회전 각도를 키워서 다시 뽑아드릴 수 있어요
- **루프 방식**: 지금은 단순 반복(0→7→0)이라 7번에서 0번으로 넘어갈 때 아주 살짝 튈 수 있습니다. 이어붙임이 신경 쓰이면 프레임 순서를 왕복(0~7~0)으로 늘려서 더 부드럽게 만들 수도 있습니다
